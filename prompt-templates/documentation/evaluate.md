# 回答质量评估

请从「评估」而非「审计」的角度，评价本次会话中自己的回答质量：

## 完成度

- 本次回答在多大程度上解决了用户的问题？（高 / 中 / 低）
- 简要说明理由。

## 遗漏与偏差

- 是否遗漏了用户隐含的需求、约束或上下文？
- 是否存在理解偏差？

## 可改进之处

- 表述、结构、技术细节等方面有哪些可以改进的地方？
- 是否有更简洁、更准确的呈现方式？

## 后续建议

- 如果下次遇到类似问题，可以如何做得更好？
- 有哪些模式或检查项值得复用？

## 输出格式

请用平和、建设性的语气输出，避免指责性语言。重点放在「下次如何更好」，而不是「本次哪里错了」。
