# 目标对齐

请读取 `.claude/state/goal-tracker.md`，将本次会话产出与目标进行对照：

## 已完成或推进的目标

- 哪些目标因本次会话而完成或取得进展？
- 进展的具体证据是什么？

## 出现偏差的目标

- 哪些目标的实现方式与预期不同？
- 偏差是合理的还是需要纠正？

## 新增或调整的目标

- 是否需要新增目标？
- 是否需要拆分、合并或调整现有目标的优先级？

## 阻塞目标

- 哪些目标当前被阻塞？
- 阻塞原因是否有变化？

## 输出

请输出更新后的 `goal-tracker.md` 内容草案，使用 YAML frontmatter + Markdown body 格式，保持与现有文件结构一致。
