# 交接摘要

## 核心成果

重新设计了 `/summarize` 归档系统，从「迁移 session.md」升级为「审查驱动、内容分层、并发安全」的架构。

## 关键产物

| 产物 | 位置 | 说明 |
|------|------|------|
| 归档 hook | `hooks/documentation/archive.sh` | 支持会话目录、workflow 推断、index.md 维护 |
| 前置检查 hook | `hooks/documentation/pre-summarize.sh` | 旧路径检测、并发冲突检测 |
| 退出检查 hook | `hooks/documentation/session-exit.sh` | 支持会话目录 |
| documentation skill | `skills/documentation/SKILL.md` | 新增 AUDIT 阶段与内容分层 |
| 审查模板 | `prompt-templates/documentation/audit.md` | 覆盖五类审查问题 |
| 打包模板 | `prompt-templates/documentation/package.md` | 更新归档方案说明 |
| 协作文档 | `CLAUDE.md` | 新增状态架构与归档规则 |
| 当前会话状态 | `.claude/state/sessions/default/` | 中间状态迁移至此 |

## 决策与待办

- **决策**：session.md / plan.md 不归档；handoff / architecture 按 workflow 命名归档；CLAUDE.md 优化建议不自动写入。
- **待办**：观察首次 `/summarize` 实际运行效果，根据反馈微调 AUDIT 模板。

## 风险提示

- 旧 `.claude/state/session.md` 与 `.claude/state/plan.md` 已删除，后续会话应使用 `sessions/<id>/` 目录。
- 并发会话必须设置 `CLAUDE_SESSION_ID`。

## 归档方案

- workflow 类型：build
- `handoff.md` → `archive/2026-07-15-重新设计归档系统-build-handoff.md`
- `session.md` / `plan.md` 不归档
