# 分支职责

- 稳定分支：只接收验证通过的集成里程碑。
- 集成分支：注册、合并和关闭会话，收敛全局文档。
- `codex/session/<session-id>`：承载单个长期会话的代码、测试和状态增量。

# 注册与进入

新会话必须先在集成分支登记 `active-sessions.yaml`，创建最小 `session.md` 和
`plan.md`，提交注册信息后从集成分支创建会话分支。进入已有会话前工作树必须干净，
分支必须与清单登记一致。

# 开发与检查点

提交标题建议使用 `<type>(<session-id>): <imperative summary>`。代码、测试、契约和
会话状态应在同一行为提交中一致。禁止使用长期 stash 或未提交文件承担会话记忆。

# 集成与关闭

会话成果先合入集成分支，重新运行治理检查和测试；稳定后再进入稳定分支。关闭会话
前先收敛长期事实，再移除活跃清单项和会话目录，最后删除已合并分支。
